# Tools Penghitung Pesanan Barang

Aplikasi kasir berbasis Python CLI untuk menhitung total belanjaan,diskon, dan PPN otomatis.

## Cara Pakai

1. jalankan aplikasi lewat terminal:

```bash
python main.py
```

2. pilih kode produk, masukan jumlah barang, dan diskon.
3. Riwayat transaksi otomatis tersimpan di folder `data/riwayat_pesanan.csv`.
